# WorkSpace Security Analyst & Network Monitoring — Glossary v1

- **Approved Asset Inventory** — operator-controlled source of truth for monitored assets.
- **Observed Network State** — current measured/discovered state; not automatically authoritative.
- **Observation** — one raw/normalized measurement from a collector.
- **Event** — normalized log/security record.
- **Template** — stable generalized pattern representing repeated logs.
- **Finding** — evidence-backed condition worth tracking; not necessarily an incident.
- **Incident Candidate** — correlated findings that may represent one underlying problem/security event.
- **Confirmed Incident** — requires the organization's confirmation workflow; AI alone cannot assign this status.
- **Data Gap** — missing/stale/incomplete required evidence.
- **Evidence Coverage** — fraction of required sources/collectors successfully represented in an analysis window.
- **Flow Metadata** — connection/session facts without routine packet payload storage.
- **PCAP** — packet capture containing packet data; denied by default in routine monitoring.
- **Baseline** — versioned historical statistical profile of measured behavior.
- **NAS Archive Receipt** — deterministic record proving a report bundle was validated and archived or remains pending.
