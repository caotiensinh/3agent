## Package boundary

No runtime code, real LAN authority, installer change, collector scheduler, packet capture, new dependency, device credential, or NAS credential is included in this research package.

The sidebar and workflow documents are product/architecture contracts only. Opening or rendering the proposed Security Analyst UI must never itself start a collector or grant network authority.
