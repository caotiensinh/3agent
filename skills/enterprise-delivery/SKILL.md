# Enterprise Delivery

Use for durable project, operational, or release decisions.

- Convert intent into objective, constraints, non-goals, acceptance evidence, owner, and dependencies.
- Record concrete risks with likelihood, impact, blast radius, mitigation, owner, and re-evaluation trigger.
- For shared-state changes define preconditions, validation, rollback trigger, and rollback path before execution.
- Record durable decisions with alternatives, tradeoffs, assumptions, and invalidation triggers.
- Derive status from source-of-truth evidence; never invent progress or completion.
- Release readiness requires exact-candidate evidence for every mandatory gate or an authorized waiver.
- Prefer the smallest process that preserves auditability; planning does not grant execution authority.
